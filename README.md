## 投递与联系

1. 打开 [NVIDIA Careers](https://www.nvidia.com/en-us/about-nvidia/careers/)，搜索职位 ID（例如 `JR2016747`），查看完整 JD 并完成投递。
2. 如希望进一步了解岗位，可邮件联系 [Echo Xu](mailto:echox@nvidia.com)：**echox@nvidia.com**。
3. 邮件中可以注明感兴趣的职位 ID、目前所在地及主要技术方向，便于沟通。

建议邮件主题：`职位咨询｜JR2016747｜姓名｜GPU Profiling / CUDA`

也欢迎把仓库分享给从事大模型训练、分布式系统、性能优化、数据平台、系统软件、GPU Profiling、HPC 或 AI Infra 的朋友。
